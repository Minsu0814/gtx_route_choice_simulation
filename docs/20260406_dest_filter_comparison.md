## 4. 핵심 발견

### 4.1 도착필터 효과 (성공)

1. **Omitted variable bias 해소**: total_ivt가 walk 없이도 3모형 모두 음수 (-0.020 ~ -6.477)
2. **Walk 효과 축소**: rho-sq 개선 +0.17 -> +0.01 (95% 감소)
3. **기본 모형 성능 향상**: Spec A rho-sq 0.27 -> 0.35 (+0.07)
4. **Beta 안정성**: walk 유무에 따른 beta 변화 미미 (이전: 극적 변화)

### 4.2 남은 문제

1. **ivt_train/gtx 양수**: 구조적 식별 문제 (모드 지시자). 도착필터로 해결 불가
2. **전체 rho-sq 하락**: 0.44 -> 0.36 (필터링으로 데이터 30% 감소 + 쉬운 egress 단서 제거)
3. **ML transfer_walk sigma 과대**: E[b] = -52 ~ -55 (비현실적 크기, sigma 3.4)

도착정류장 필터링으로 **omitted variable bias 문제가 해결**됨:

- IVT beta가 walk 변수 없이도 올바른 음수 부호

## 6. IVT split 양수 beta 원인 분석

### 6.1 현상

Spec C/D에서 ivt_train, ivt_gtx의 beta가 양수 (MNL/TasteNet):

| 변수      | MNL (Spec C) | TasteNet (Spec C) |
| --------- | ------------ | ----------------- |
| ivt_bus   | -0.025       | -0.378            |
| ivt_train | **+0.010**   | **+0.175**        |
| ivt_gtx   | **+0.161**   | **+0.177**        |

"열차를 오래 탈수록 선호" — 직관에 반하는 결과.

### 6.2 원인: Choice set 내 대체 관계 (substitution)

**ivt_train vs ivt_bus 상관: -0.650** (48,977개 OD, choice set 내)

같은 OD의 대안들에서 train IVT가 길면 bus IVT가 짧음. 즉 "버스 많이 타는 경로" vs "지하철 많이 타는 경로"가 **대체 관계**.

이 때문에 ivt_train이 높은 경로는 곧 **환승이 적고 walk이 짧은 경로**:

**train_only OD에서 chosen vs non-chosen:**

| 변수          | chosen | non-chosen | 차이      |
| ------------- | ------ | ---------- | --------- |
| ivt_train     | 46.1분 | 43.5분     | **+2.7**  |
| num_transfers | 0.84   | 1.31       | **-0.47** |
| transfer_walk | 79초   | 88초       | **-8초**  |

> chosen 경로는 train IVT가 더 길지만 **환승 0.5회 적고 walk 9초 짧음**.

### 6.4 메커니즘

```
Total IVT로 추정 시:
  V = β_ivt * total_ivt + β_tr * transfers + ...
  → β_ivt < 0 (정상): IVT 길면 비효용

IVT split으로 추정 시:
  V = β_bus * ivt_bus + β_train * ivt_train + β_tr * transfers + ...
  → ivt_train과 transfers의 상관 = -0.65
  → "ivt_train 높음 = 환승 적음 = 좋은 경로" 패턴
  → β_train이 transfers 효과를 흡수하여 양수
```

이는 omitted variable bias가 아니라 **구조적 collinearity**. ivt_train은 choice set 내에서 "직통 열차 경로"의 **지시자(indicator)** 역할을 하며, 수단별 IVT의 시간 가치를 순수하게 식별할 수 없음.

### 6.5 카테고리별 패턴 분석

각 카테고리의 **해당 수단 IVT** 기준으로, chosen 경로의 IVT와 num_transfers를 non-chosen 평균과 비교하여 패턴 분류.

패턴 정의:

- **B) IVT↑ + transfers↓**: 양수β 유발 — 환승 감소 효과가 IVT에 흡수됨
- **C) IVT↑ + transfers=**: 양수β 유발 — IVT 길어도 선호
- **D) IVT↑ + transfers↑**: 음수β 지지 — IVT↑이면 비선호
- **E) IVT↓ + transfers↓**: 부호 정상 — IVT↓ + transfers↓ 동시
- **F) IVT↓ + transfers=**: 부호 정상 — IVT↓이면 선호
- **G) IVT↓ + transfers↑**: 부호 정상 — IVT↓ 효과가 transfers↑보다 큼

상관: **+0.070** — bus+train에서 열차를 많이 탈수록 환승도 많아지는 구조 (bus→train 환승).

#### train+gtx (90 ODs) — ivt_train / ivt_gtx 각각

**ivt_train 기준:**

| 패턴               | ODs |  비율 |
| ------------------ | --: | ----: |
| B+C) 양수β 유발    |  29 | 32.2% |
| D+E+F+G) 부호 정상 |  61 | 67.8% |

상관: **-0.722**

**ivt_gtx 기준:**

| 패턴               | ODs |  비율 |
| ------------------ | --: | ----: |
| B+C) 양수β 유발    |   8 |  8.9% |
| D+E+F+G) 부호 정상 |  82 | 91.1% |

상관: **+0.318** — GTX 많이 타면 환승도 늘어남.

### 6.6 종합 요약

| 카테고리   | IVT 변수  |   N ODs |   상관 | 양수β유발 (B+C) | 부호정상 (D~G) | MNL β 부호 |
| ---------- | --------- | ------: | -----: | --------------: | -------------: | ---------- |
| bus_only   | ivt_bus   | 215,557 | -0.311 |           58.6% |          41.5% | **음수**   |
| train_only | ivt_train |  25,915 | -0.673 |           66.4% |          33.6% | **양수**   |
| bus+train  | ivt_bus   |  64,270 | -0.415 |           47.9% |          52.1% | 음수       |
| bus+train  | ivt_train |  64,270 | +0.070 |           28.6% |          71.4% | 양수       |
| train+gtx  | ivt_train |      90 | -0.722 |           32.2% |          67.8% | 양수       |
| train+gtx  | ivt_gtx   |      90 | +0.318 |            8.9% |          91.1% | 양수       |

핵심 발견:

1. **상관 강도가 beta 부호를 결정**: -0.31(bus) → 음수β, -0.67(train) → 양수β
2. **Pattern B 비율보다 상관 강도가 중요**: bus_only는 58.6%가 양수β 유발 패턴이지만, 상관이 약해(-0.31) beta는 음수
3. **bus+train의 ivt_train은 양의 상관(+0.07)**: 열차 탈수록 환승 증가 — train_only(-0.67)와 정반대 구조
4. **total_ivt는 전 카테고리에서 음의 상관** (-0.31 ~ -0.70) → Total IVT spec이 안정적인 이유

### 6.7 결론

#### 식별 불가의 본질

IVT split이 개념적으로 틀린 것은 아니다. 승객이 버스 30분과 지하철 30분을 다르게 느끼는 것은 사실이다. 문제는 한국 대중교통 네트워크에서 **직통 경로 = 한 수단으로 오래 타는 경로 = 환승 적은 경로**라는 구조가 너무 강해서, 수단별 시간가치를 분리할 수 있는 variation이 부족하다는 것이다.

따라서 "IVT split is inappropriate"가 아니라, **"not identifiable given the substitution structure in the choice set"**이 정확한 진단이다.

#### 상관과 beta 부호의 관계

| 비교 항목             | ivt_bus (bus_only) | ivt_train (train_only) |
| --------------------- | ------------------ | ---------------------- |
| IVT vs transfers 상관 | -0.311             | -0.673                 |
| MNL β 부호            | **음수** (-0.025)  | **양수** (+0.010)      |

주력 수단 IVT와 transfers의 within-choice-set 상관이 강할수록 양수 beta 위험이 높다. 다만 -0.3 / -0.67이라는 임계값은 이 데이터셋에서의 경험적 관찰이므로, 일반화보다는 **"상관이 강할수록 식별 실패 위험 증가"**로 해석해야 한다.

#### Total IVT + ASC의 의미와 한계

Total IVT + ASC는 현실적으로 가장 안정적인 스펙이다:

- total_ivt는 전 카테고리에서 음의 상관(-0.31 ~ -0.70)이 수단별로 합산되면서 substitution 패턴이 상쇄됨
- 3개 모형(MNL, ML, TasteNet) 모두 안정적 음수 beta

단, 이 접근의 대가는 **수단별 시간가치 차이를 포기**하는 것이다:

```
V = β_ivt × (모든 수단 IVT 합) + ASC_train + ASC_gtx + ...
→ "시간은 수단과 무관하게 동일한 비효용"이라는 가정
→ 수단 선호는 ASC(상수)로만 포착
```

ASC_train+gtx가 양수(+5.5)이므로 "GTX 경로를 선호한다"는 확인되지만, **"GTX 탑승시간 1분의 가치가 버스와 다른가?"에는 답할 수 없다.**

#### 논문 서사

> 수단별 IVT 분리를 시도했으나, choice set 내에서 주력 수단 IVT와 환승 횟수의 강한 음의 상관(structural collinearity)으로 인해 식별이 불가능했다. 이는 한국 대중교통 네트워크에서 직통 경로가 환승 경로보다 한 수단의 탑승시간이 길어지는 구조적 특성에 기인한다. 따라서 Total IVT + ASC 더미로 시간 비효용과 수단 선호를 분리하는 접근을 채택한다.
