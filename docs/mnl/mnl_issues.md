## 5. GTX 선택확률 과추정 문제 (AFC 검증 결과)

### 현상

GTX-A 시나리오에서 MNL 확률 기반 GTX 이용자 밀도를 AFC 실측과 H3 셀(res 8) 단위로 비교한 결과:

| 지표 | AFC | OTP(MNL) | OTP/AFC |
|------|-----|----------|---------|
| GTX>0 H3 셀 수 | 833 | 1,915 | **2.30배** |
| 겹치는 셀 GTX 인원 합계 | 262,839 | 635,299 | **2.42배** |
| 총 통행 인원 합계 | 50,574,307 | 50,518,171 | **1.00** |
| 셀별 OTP/AFC 비율 중앙값 | - | - | **2.76배** |

- 총 통행량은 거의 동일(1.00배) → OD별 tc 배정은 정상
- **GTX 이용자만 2.42배 과추정** → MNL 선택확률 문제
- OTP에만 존재하는 셀 1,092개 (AFC에는 GTX 이용자 없음)

### 셀별 과추정 편차

| 위치 | AFC GTX | OTP GTX | 비율 |
|------|---------|---------|------|
| 킨텍스 (37.718, 126.727) | 28,383 | 29,282 | 1.03 (양호) |
| 서울역 (37.556, 126.973) | 38,682 | 75,314 | 1.95 |
| 연신내 (37.618, 126.918) | 11,054 | 49,056 | **4.44** |
| 성남 (37.508, 127.066) | 1,612 | 26,984 | **16.74** |

- 종점(킨텍스, 동탄)은 비교적 정확하나, 중간역/원거리 셀에서 심각한 과추정

### 공간 패턴 상관분석 (H3 셀 수준 산점도)

AFC와 OTP가 모두 GTX > 0인 823개 H3 셀에서 로그 척도 비교:

| 지표 | 값 | 해석 |
|------|-----|------|
| Pearson r (log) | **0.813** | 강한 선형 상관 |
| Spearman ρ | **0.801** | 강한 순위 상관 |
| OLS 기울기 | 1:1선 상방 | 체계적 과추정 |

- **고밀도 구간** (GTX역 인근, log 8~10): 1:1선에 근접 → 핵심 역세권은 정확
- **저밀도 구간** (원거리, log 1~4): 산포 크고 과추정 → MNL이 미미한 확률도 배정

> **핵심 해석**: 시뮬레이션은 GTX 이용이 **어디서** 발생하는지(WHERE)는 정확히 재현하나, **얼마나**(HOW MUCH) 발생하는지는 체계적으로 과추정. 이는 영향권 분석의 upper bound로 해석 가능.

### 밀도맵 3패널 비교

AFC 기준 동일 색상 스케일로 3개 히트맵 비교:

| 패널 | 내용 | H3 셀 수 |
|------|------|----------|
| (a) AFC 실측 | GTX 이용자 출발지 밀도 | 833개 |
| (b) OTP 전체 | 시뮬레이션 GTX 밀도 | 1,915개 |
| (c) OTP 겹침만 | AFC와 겹치는 셀만 추출 | 823개 |

- (a)와 (c) 비교 시 공간 패턴이 거의 일치 → 시뮬레이션의 공간적 타당성 확인
- (b)의 추가 셀(1,092개)은 대부분 저밀도 노이즈

### 원인 분석

1. **has_gtx ASC = +0.469 과대**: GTX가 경로에 포함되기만 하면 무조건 보너스. 거리/접근시간과 무관하게 적용되어 원거리 OD에서도 GTX 확률이 과대하게 배정됨

2. **fare β = 0**: GTX 요금(기본 철도 대비 2~3배)이 효용에 전혀 반영되지 않음. GTX 보너스만 있고 요금 패널티가 없는 구조

3. **has_train ASC = +1.481과 중첩**: GTX 경로는 has_gtx(+0.469) + has_train(+1.481) = **+1.950** 보너스가 동시에 적용. 일반 철도(+1.481)보다 훨씬 큰 선호도가 부여됨

4. **학습 데이터에 GTX 실측 없음**: 478,345 OD 학습 데이터는 기존 교통수단 기반. has_gtx 계수는 GTX 실제 이용 패턴이 아닌 기존 철도 선호에서 유추된 값

### 하류 영향

이 과추정이 영향권 분석에 연쇄적으로 전이:

- **밀도맵**: OTP 밀도가 AFC보다 넓고 진하게 나타남
- **h3_delta_tt**: GTX 확률이 과대 → H3별 가중평균 통행시간 차이(delta_tt) 과대
- **gtx_share**: GTX 가중통행량 / 전체 가중통행량이 실제보다 높게 산출
- **영향권**: CII > 0인 H3가 4,329개(100%) → 수도권 전체가 영향권으로 분류
  - A1: delta_tt > 0.1분인 셀은 160개(3.7%)에 불과하나 전체가 영향권으로 잡힘

### 해결 방향

| 방안 | 설명 | 난이도 |
|------|------|--------|
| **GTX ASC 캘리브레이션** | AFC 실측 기반으로 has_gtx 계수를 재추정 (H3별 GTX 분담률 매칭) | 중 |
| **fare 계수 활성화** | GTX 차등요금이 반영되도록 fare β 재추정 또는 외부값 적용 | 중 |
| **GTX 접근거리 페널티** | GTX역까지 접근시간이 길수록 추가 디스카운트 (interaction term) | 중 |
| **확률 임계값 적용** | 영향권 분석 시 GTX prob < 0.01인 OD 제외 (사후 보정) | 하 |

### 구조적 한계 인식

OTP(RAPTOR)는 시간 기반으로 가능한 경로를 탐색하므로, GTX가 빠르기만 하면 접근시간이 길어도 대안 집합에 포함하는 것은 정상 동작이다. MNL 역시 대안 집합에 포함된 경로에 0이 아닌 확률을 배정하는 것이 이론적으로 올바른 작동 방식이다.

AFC에서 GTX 이용자가 0인 H3 셀 중 OTP에서 GTX가 배정된 셀이 1,092개 존재하며, 이 중 59%(644개)는 가중통행량 1명 미만으로 사실상 노이즈이나 밀도맵에는 표시된다. 이는 MNL 기반 루트초이스 시뮬레이션의 본질적 특성으로, 자의적 필터링(접근시간 상한, 확률 임계값 등)으로 보정할 경우 논문에서 정당화하기 어렵다.

### 현실적 대응

1. **영향권 분석 단계에서 처리** — `gtx_share > 0` 또는 `delta_tt > threshold`인 셀만 영향권 대상으로 한정. 분석 방법론 차원이므로 정당화 가능
2. **논문에 한계점으로 기술** — MNL 특성상 GTX 이용자 과추정 경향이 있으며, AFC 검증 결과 OTP/AFC 비율 2.02배(β=+0.106 기준)라고 명시

## 6. CII 영향권 분류: `gtx_share == 0` 필터 적용 근거

### 수정 내용

CII(Composite Influence Index) 기반 영향권 분류에서, **퀀타일 분류 전** 다음 필터를 적용:

```python
base.loc[base['gtx_share'] == 0, 'cii'] = 0
```

`gtx_share == 0`인 H3 셀은 CII = 0으로 강제하여 Non-Influence로 분류.

### 적용 이유

CII는 4개 지표의 가중합으로 구성:

```
CII_h = w_S · S_h + w_NBI · NBI_h + w_E · E_h + w_Sig · Sig_h
```

문제: GTX 통행이 0인 셀에서도 NBI, Effect Size, Significance 지표가 우연히 양수값을 가질 수 있음.
- Wilcoxon 검정이 소수 OD에서 우연히 유의하게 나오는 경우
- NBI가 요금 차이 등으로 미세하게 양수인 경우

→ **GTX 이용자가 없는데 영향권으로 분류되는 모순 발생**

필터 적용 전: CII > 0인 셀 = 4,329개 (100%) → 수도권 전체가 영향권
필터 적용 후: gtx_share > 0인 셀만 영향권 대상 → 실질적 영향권만 분류

### 논문 정당화

이 필터는 자의적 임계값 설정이 아닌, **논리적 필요조건**:

> "GTX 통행 분담률이 0인 H3 셀은 GTX 서비스의 직접적 영향이 없으므로, 부차적 지표(NBI, effect size, significance)의 통계적 노이즈로 인한 오분류를 방지하기 위해 영향권 분류에서 제외하였다."

**영문 표현 예시:**
> "H3 cells with zero GTX modal share (gtx_share = 0) were excluded from the influence zone classification, as these cells have no GTX ridership and any non-zero CII values arise from statistical noise in subsidiary indicators."

### 공격 가능성 검토

| 우려 | 반론 |
|------|------|
| 자의적 필터링 아닌가? | GTX 통행 = 0이면 GTX 영향 = 0은 자명. 방법론적 판단이지 임계값 조정이 아님 |
| 미미한 GTX 확률도 제외되나? | `gtx_share > 0`이면 포함. MNL이 배정한 아주 작은 확률(0.001%)도 영향권 후보에 남음 |
| 왜 NBI 등에서 양수가 나오나? | 소수 OD의 통계적 노이즈. GTX 없이도 시나리오 간 경로 차이가 미세하게 존재할 수 있음 |

### 주의사항

`gtx_share > 0`이 아닌 `== 0`만 제외하므로, MNL이 아주 미미한 GTX 확률을 배정한 셀도 영향권에 포함됨. 이 부분은 논문 한계점에서 다음과 같이 기술:

> "MNL assigns non-zero probability to all alternatives in the choice set, resulting in minimal but positive GTX share for cells distant from GTX stations. This is an inherent property of the logit model rather than a modeling error."

### 향후 과제

| 방안 | 설명 | 기대효과 |
|------|------|----------|
| **fare 계수 활성화** | 수도권 통합요금제 구조상 OD 내 요금 분산이 0이라 추정 불가였음. GTX 차등요금 데이터 확보 시 재추정 | GTX 고요금이 자연스럽게 억제 역할 |
| **Nested Logit** | 모드별 둥지 구조 (GTX/철도/버스) → IIA 위반 완화, GTX-철도 간 대체성 반영 | 유사 대안 간 확률 과배분 방지 |
| **GTX 접근거리 interaction term** | `has_gtx × access_time` 교차항 추가 → 접근시간 길수록 GTX 효용 감소 | 원거리 OD 과추정 완화 |
| **Mixed Logit** | 개인별 선호 이질성 반영 (random coefficients) | 모형 유연성 향상, WTP 분포 추정 가능 |
| **AFC 기반 재추정** | GTX-A 개통 후 AFC 실측으로 revealed preference 데이터 구축 → MNL 재학습 | 근본적 해결 (데이터 의존) |
