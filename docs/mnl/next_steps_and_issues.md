## 1. 해결된 이슈

### 1.1 fare β = 0 → **해결 (2026-03-21)**

- 버스유형별 차등요금 반영 (마을 1,200 / 광역 3,000 / 공항리무진 별도)
- fare β = -0.362, t = -259.8 (강하게 유의)

### 1.2 walk/IVT 비율 과대 → **해결 (2026-03-21)**

- log(1+walk) 사양 + 모드별 IVT + distance 제거
- walk/IVT "비율"이 아닌 비선형 구조로 대체 → 직접 비교 불가하지만 모형 적합도 대폭 개선
- bus_ivt/train_ivt 비율 = 0.89x (합리적)

### 1.3 PSL 보정 → **효과 없음 확인 (2026-03-21)**

- stop-based, leg-based, 둘 다 시도
- 대중교통 경로 간 정류장 중첩이 도로 네트워크만큼 크지 않음
- ρ² 개선 < 0.0001, Top-1 변화 < 0.01%

## 2. 남은 이슈

### 2.1 wait β = 0 → 구조적 한계 (해결 불필요)

- **원인**: OTP가 같은 출발시간대에 K-best 생성 → 대안 간 wait 차이 미미
- num_transfers가 환승 대기를 이미 흡수
- Headway 기반, log 변환, per_boarding 정규화 모두 β=0
- **결론**: wait 제거가 적절. 논문에서 구조적 한계로 기술

### 2.2 GTX 과추정 → 미해결

- has_gtx ASC가 양수 → 원거리 OD에서도 GTX 확률 배정
- fare β 활성화로 일부 완화되었을 것이나 재검증 필요

### 2.3 매칭 기반 내생성 → 구조적 한계

- choice_prob ↔ sim_composite r=0.79
- log(walk) 사양으로 증상 완화했으나 근본 원인은 유지
- 딥러닝 모형으로 개선 예정
