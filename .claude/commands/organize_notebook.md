# Jupyter 노트북 정리

주어진 Jupyter 노트북(.ipynb)을 정리하고 구조화합니다.

## 대상 파일

$ARGUMENTS

## 작업 내용

1. **제목 추가**: 노트북 최상단에 마크다운 셀로 제목과 설명 추가
   - `# 제목` 형식
   - `> 한 줄 설명` (blockquote)
   - 목적, 출력 컬럼 등 주요 정보 포함

2. **섹션 헤더 추가**: 논리적 단위로 섹션 구분
   - `---` (수평선)으로 시각적 구분
   - `## 1. 설정` - import, 경로 설정 등
   - `## 2. [본문]` - 주요 로직
   - `## 3. [결과/저장]` - 출력, 저장 등
   - 섹션 이름은 내용에 맞게 조정

3. **불필요한 셀 정리**
   - 빈 셀, 테스트 셀, 주석 처리된 오래된 코드 제거
   - 중복 코드 정리

4. **코드 셀 정리**
   - 관련 코드끼리 그룹화
   - 필요시 주석 추가

## 출력 구조 예시

```
# 제목
> 설명

---
## 1. 설정
[import, 경로 설정]

---
## 2. 데이터 처리
[주요 로직]

---
## 3. 결과 저장
[출력, 저장]
```
